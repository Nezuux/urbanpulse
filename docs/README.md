# Documentation du projet UrbanPulse

Ce dossier centralise l’ensemble des livrables de projet, organisés par jalons.

## Structure

```text
docs/
├── J0-kickoff/
├── J1-cadrage/
├── J2-pilotage/
├── J3-gouvernance/
├── J4-plateforme/
└── J5-ia-restitution/
```

## Objectif

Chaque dossier de jalon contient la documentation associée à une étape du développement du projet UrbanPulse, afin de conserver une traçabilité claire des décisions, livrables et preuves d’avancement.
