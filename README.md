# UrbanPulse

UrbanPulse est un projet fil rouge de Mastère 2 Data & IA, porté par une équipe de trois profils complémentaires : Data Engineer et Data Analyst.

## Objectif

Concevoir progressivement une plateforme d’aide à la décision fondée sur des données réelles de mobilité, transport, environnement et événements urbains, avec pour territoire d’étude Bordeaux.

## Périmètre

Le projet vise à mettre en place un MVP évolutif, structuré par jalons, qui s’enrichit au fil du temps selon les besoins du client et les contraintes techniques du projet.
